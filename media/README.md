# Your own visuals

Drop images or videos here and the dashboard uses them on the next page reload. Nothing here is required.

- `background.mp4` / `background.webm` / `background.jpg` / `background.png`: a looping backdrop behind the dashboard (kept dark and subtle).
- `agent-<id>.png` (or `.jpg`, `.webp`, `.mp4`): a portrait for one agent, shown in the Agents tab. Ids:
  `crypto`, `market`, `hype`, `detective`, `news`, `professor`, `predictor`, `risk`, `buyer`, `optimizer`.
- `logo.png`: replaces the TRADINGBOTTY wordmark.

Tips: square portraits around 512x512, a background video of 5-10 seconds that loops cleanly, dark colors.
Higgsfield (or any image/video generator) works well for these.
